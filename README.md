# Sprint_6

Проект Спринт 6

Созданы автотесты для проверки функциональности сервиса https://qa-scooter.education-services.ru/

В папке tests содержатся файлы с тестами, разделенные по страницам: 
- test_main_page.py содержит тесты для проверки главной страницы: 
    - test_click_on_question_open_answers - тест для проверки отображения ответов на вопросы при клике на вопрос в разделе "Вопросы о важном"
    - test_click_on_yandex_open_dzen - тест для проверки, что по клику на логотип Яндекс открывается страница Яндекс.Дзен
    - test_click_on_scooter_open_main_page - тест для проверки, что по клику на логотип Самокат открывается главная страница Самокат

- test_create_order.py содержит тесты для проверки формы создания заказа:
    - test_new_order_from_headder - тест для проверки создания заказа, с использованием 2х наборов данных
    - test_click_on_second_order_button_open_create_order_form - тест, что кликнув на вторую кнопку "Заказать" пользователь попадает на форму создания заказа

В папке locators содержатся файлы с локаторами, разделенными по страницам:
    - main_page_locators.py - локаторы главной страницы
    - oder_page_locators.py - локаторы страницы создания заказа

В папке fixture содержатся файлы с тестовыми данными, разделенными по страницам:
    - faq_data.py - данные для раздела "Вопросы о важном"
    - order_data.py - данные для тестирования формы создания заказа
    - url_data - содержит url использованных в тестах страниц

В папке page_object содержатся файлы с методами, разделенными по страницам:
    - base_page.py содержит базовые методы, применимые к любой странице
    - main_page.py содержит методы для тестов главной страницы
    - order_page.py содержит методы для тестов страницы создания заказа
